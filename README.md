# SQL Aggregation Basics – Veda Technology Internship

## 📌 Project Overview
This project is part of Task 22 of the Veda Technology Internship. The main objective is to understand and practice SQL aggregate functions to analyze and summarize data efficiently.

## 🎯 Objectives
- Understand SQL aggregate functions.
- Calculate total, average, minimum, and maximum values.
- Count the number of records.
- Group data using GROUP BY.
- Filter grouped results using HAVING.
- Perform basic data analysis using SQL.

## 🛠️ Technologies Used
- SQL
- MySQL
- Online SQL Editor
- GitHub

## 📊 Dataset Description
A sample Sales dataset is used for practicing SQL aggregation queries.

The dataset contains the following columns:

| Column Name | Description |
|---|---|
| SaleID | Unique sales ID |
| Product | Product name |
| Category | Product category |
| Amount | Sales amount |
| Quantity | Quantity sold |

## 📚 SQL Functions Used
1. COUNT() – Counts the number of records.
2. SUM() – Calculates the total value.
3. AVG() – Calculates the average value.
4. MIN() – Finds the minimum value.
5. MAX() – Finds the maximum value.
6. GROUP BY – Groups records based on a column.
7. HAVING – Filters grouped results.
